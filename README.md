# Brown Bag Presentations

This repository contains Marp source for internal brown bag presentations.

## Presentation

- Sources: any `*.marp.md` files in the repository, excluding generated/scratch folders
- Published pages: generated by GitHub Actions, with one page per Marp deck
- Release PDFs: generated by GitHub Actions and attached to tagged GitHub Releases

## Local Preview

Run the same Marp Docker image used by the workflow:

```powershell
docker run --rm `
  -v "${PWD}:/work" `
  -w /work `
  -p 8080:8080 `
  marpteam/marp-cli `
  --html `
  --watch `
  --server outputs
```

Then open:

```text
http://localhost:8080/modern-development-feedback-loops.marp.md
```

## Add Another Presentation

Add another Marp file anywhere in the repository using the `*.marp.md` naming convention, for example:

```text
outputs/my-next-brown-bag.marp.md
```

On push to `main`, GitHub Actions will:

- Render each deck to its own GitHub Pages route.
- Build a root index page linking to every deck.
- Generate a PDF for every deck.
- Upload all PDFs as workflow artifacts.

On tagged releases, the workflow will attach all generated PDFs to the release.

## Release

Create and push a tag to publish a GitHub Release with the rendered PDF attached:

```powershell
git tag v0.1.0
git push origin v0.1.0
```
