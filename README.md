# Brown Bag Presentations

This repository contains Marp source for internal brown bag presentations.

## Presentation

- Source: `outputs/modern-development-feedback-loops.marp.md`
- Published page: generated by GitHub Actions from the Marp source
- Release PDF: generated by GitHub Actions and attached to tagged GitHub Releases

## Local Preview

Run the same Marp Docker image used by the workflow:

```powershell
docker run --rm `
  -v "${PWD}:/work" `
  -w /work `
  -p 8080:8080 `
  marpteam/marp-cli `
  --html `
  --watch `
  --server outputs
```

Then open:

```text
http://localhost:8080/modern-development-feedback-loops.marp.md
```

## Release

Create and push a tag to publish a GitHub Release with the rendered PDF attached:

```powershell
git tag v0.1.0
git push origin v0.1.0
```
